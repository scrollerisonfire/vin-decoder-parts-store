## Слоеве

### 1. Frontend (потребителски интерфейс)
- **VIN Lookup** — поле за VIN, връща декодирана инфо (марка, модел, година, двигател)
- **Каталог** — навигация по марка → модел → категория част
- **OEM схеми** — explosion view диаграми (за BMW през RealOEM)
- **Сравнение на цени** — таблица с цени от различни магазини
- **AI Чат** — "Имам Opel Astra H 1.7 CDTI, нужни са ми спирачни накладки до 80 лв"
- **Checkout** — избор на офис на Еконт/Спиди + плащане

### 2. API Gateway (входна точка)
- JWT автентикация
- Rate limiting (защита от abuse и от изхарчване на платените API)
- Централизирано логване
- Маршрутизация към микросървиси

### 3. Бизнес сървиси
| Сървис | Отговорност |
|--------|-------------|
| **VIN Service** | Декодиране на VIN, кеш на резултати |
| **Parts Service** | CRUD на части, наличности, цени |
| **Compatibility Service** | Дали част № X пасва на автомобил Y |
| **Pricing Service** | Сравнение на цени между магазини |
| **AI Recommendation** | Препоръки за хора, които не разбират |
| **Shipping Service** | Еконт + Спиди — товарителници, проследяване |
| **Vehicle History** | CarVertical интеграция |
| **Payments Service** | Stripe / ePay.bg |

### 4. Външни API и данни
Виж `docs/02-api-strategy.md` за пълен анализ.

### 5. Data слой
- **PostgreSQL** — основни данни (части, потребители, поръчки)
- **Elasticsearch** — full-text търсене по име/OEM номер
- **Redis** — кеш на VIN декодирания (24ч), кеш на цени (15мин)
- **S3 / R2** — снимки на части, OEM схеми, PDF фактури

## Принципи на дизайна

1. **Кеш агресивно** — външните API са бавни и/или платени
2. **Graceful degradation** — ако TecDoc е down, покажи каквото има в локалната БД
3. **Webhook-first за shipping** — Еконт/Спиди пращат статуси, не питай ги
4. **Secrets никога във frontend** — всички API ключове в backend env vars
5. **Audit log за платени операции** — CarVertical, Stripe (за reconciliation)
