# 02 — API стратегия (кое API за какво)

Това е най-важният документ. Тук решаваме кои външни API да ползваме за всяка задача.

## Задача 1: Декодиране на VIN

| API | Цена | Покритие | Качество | Препоръка |
|-----|------|----------|----------|-----------|
| **NHTSA vPIC** | Безплатно | Целия свят, US фокус | Основно (марка, модел, двигател, година) | ✅ Първи избор |
| **CarAPI** (carapi.app) | Freemium | Глобално | По-богато (trim levels, опции) | Резерв за Европа |
| **TecDoc** | Платено (€€) | Европа отлично | Перфектно за части | Само ако вече имаш TecDoc |

**Стратегия:** NHTSA първо → ако върне непълна информация → fallback към CarAPI.

```
GET https://vpic.nhtsa.dot.gov/api/vehicles/DecodeVin/{VIN}?format=json
```

## Задача 2: Каталог на части по марка/модел

| API | Цена | Покритие |
|-----|------|----------|
| **TecDoc / ACES** (TecAlliance) | Платено, лиценз | 3M+ части, цяла Европа — индустриален стандарт |
| **Auto Parts Catalog** (RapidAPI) | Freemium | По-малко покритие, добро за start |
| **CarAPI** | Freemium | OEM номера ограничено |

**Стратегия:**
- **MVP**: започни с RapidAPI Auto Parts Catalog + собствена БД
- **Production**: купи TecDoc лиценз (€500–€2000/мес в зависимост от обема)

## Задача 3: OEM схеми (explosion views)

| Източник | Покритие |
|----------|----------|
| **RealOEM** | BMW (отлично), MINI |
| **EPC (Electronic Parts Catalog)** | VW, Audi, Mercedes — но не е публичен API |
| **Partsouq** | Многомарков, scraping |

**Стратегия:**
- BMW → scrape RealOEM (внимание с ToS — кеширай резултатите)
- Други марки → купи OEM каталог достъп или партнирай с локален вносител
- Алтернатива: ползвай TecDoc графики (включени в лиценза)

## Задача 4: Проверка на история на автомобил

| Услуга | Модел |
|--------|-------|
| **CarVertical** | Affiliate / revenue share — даваш VIN, получаваш отчет |
| **Carfax** | За US пазар |
| **autoDNA** | Източна Европа |

**Стратегия:** CarVertical има партньорска програма — регистрирай се на partners.carvertical.com, получаваш API ключ и комисионна за всеки отчет.

## Задача 5: Доставка

| Превозвач | API |
|-----------|-----|
| **Еконт** | Безплатно — https://ee.econt.com/services/Shipments/ |
| **Спиди** | Безплатно — https://api.speedy.bg/ |

И двете са задължителни за български пазар. Виж `backend/integrations/econt.md` и `speedy.md`.

## Задача 6: Плащания

| Провайдер | За кого |
|-----------|---------|
| **Stripe** | Карти, международно |
| **ePay.bg / EasyPay** | Български пазар, банков трансфер |
| **Borica** | Директно с банка (по-сложно) |

**Стратегия:** Stripe за карти + ePay.bg като алтернатива.

## Задача 7: AI препоръки

| Модел | Защо |
|-------|------|
| **Claude Sonnet (Anthropic)** | Най-добър за structured reasoning |
| **GPT-4o** | Алтернатива |
| **Локален Llama** | Само ако имаш големи обеми и искаш да не плащаш per call |

**Prompt стратегия:**
```
System: Ти си експерт авто-механик. Препоръчваш части на хора, които не разбират от коли.
Винаги обяснявай защо.

Input:
- VIN: {decoded vehicle}
- Какво иска: "спирачни накладки"
- Бюджет: 80 лв
- Кандидат части (от TecDoc): [list with prices, brands, ratings]

Output (JSON):
{
  "recommended": "part_id",
  "reason": "За твоята Opel Astra с 1.7 CDTI препоръчвам Bosch BP1234 защото...",
  "alternatives": [...]
}
```

## Решения "build vs buy"

| Какво | Решение |
|-------|---------|
| VIN декодер | BUY (NHTSA безплатно) |
| Каталог части | BUY (TecDoc) — невъзможно да го построиш сам |
| OEM схеми | HYBRID (RealOEM scraping за BMW, TecDoc за останалите) |
| Сравнение цени | BUILD (твоя БД + scrapers на конкуренти) |
| Shipping | BUY (Еконт + Спиди — задължително) |
| AI | BUY (Claude API) |
