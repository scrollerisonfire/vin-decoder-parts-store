# 04 — Потребителски сценарии

## Сценарий A: "Не разбирам от коли" (с AI препоръка)

```
1. Потребителят влиза → въвежда VIN: WBA3B5C50EJ986123
2. Frontend → POST /api/vin/decode
3. Backend → NHTSA vPIC API → връща: BMW 320d, F30, 2014, N47D20
4. Frontend показва: "BMW 320d 2014 ✓ Това твоят автомобил ли е?"
5. Потребителят пише в чата: "трябват ми спирачки отпред, до 200 лв"
6. Backend (AI service):
   a) TecDoc → списък със съвместими предни накладки + дискове
   b) Pricing service → цени от наши магазини + конкуренти
   c) Claude AI → препоръчва "Brembo P06024 — €68, оригинално качество"
7. Frontend показва карта с препоръката + 3 алтернативи
8. Потребителят натиска "Купи" → checkout
9. Избира офис на Еконт от dropdown (Econt API)
10. Плаща със Stripe
11. Backend → Econt API: createShipment → връща tracking № и PDF етикет
12. Email на потребителя със статус
```

## Сценарий B: "Знам какво ми трябва" (директно търсене)

```
1. Меню: BMW → Серия 3 → F30 → 2014 → Двигател → Маслен филтър
2. Frontend → GET /api/parts?make=BMW&model=F30&year=2014&category=oil_filter
3. Backend → Parts Service:
   - Локална БД (наши магазини)
   - + TecDoc API (всички съвместими)
4. Показва списък сортиран по цена
5. До всяка част: "Виж в [RealOEM]" link към explosion view
6. Останалото като сценарий A от стъпка 8
```

## Сценарий C: Проверка на история (CarVertical)

```
1. Потребителят: "Искам да проверя VIN преди покупка на кола"
2. Въвежда VIN → "Виж пълен отчет — 19.99 лв"
3. Stripe checkout
4. След плащане → Backend → CarVertical API: getReport(VIN)
5. CarVertical връща JSON + PDF link
6. Запазва се в `vin_history_reports`
7. Email + страница с отчета
8. Revenue split: CarVertical партньорска програма
```

## Сценарий D: OEM схема (за BMW)

```
1. Потребителят: "Искам да видя как е сглобен моторът на BMW E90"
2. Frontend → /catalog/bmw/e90/engine
3. Backend → RealOEM scraper / cache:
   - Връща SVG с номерирани части
4. Hover върху номер → tooltip с име и цена
5. Click → добави в кошницата
```

## Сценарий E: Сравнение на цени

```
1. Потребителят е на страницата на част "Маслен филтър Mann W712/75"
2. Backend → Pricing Service:
   - SELECT * FROM inventory WHERE part_id = X
   - + scrape конкуренти (cron job, не realtime)
3. Показва таблица:
   | Магазин       | Цена  | Доставка | Общо  |
   | Наш склад     | 12 лв | 4 лв     | 16 лв |
   | AutoZona      | 14 лв | 5 лв     | 19 лв |
   | Auto.bg       | 11 лв | 8 лв     | 19 лв |
4. "Купи най-евтиното" — ако е наше → директно; ако външно → affiliate link
```

## Сценарий F: Админ добавя нова част

```
1. Admin панел → "Нова част"
2. Въвежда OEM № → системата авто-попълва от TecDoc
3. Качва снимки → S3
4. Задава наличност и цена
5. Маркира съвместимост (от TecDoc автоматично + ръчно потвърждение)
6. Публикува
```
